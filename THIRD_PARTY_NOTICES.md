# Third-party notices

Bogen is licensed under the GNU General Public License, version 3 or later (see [LICENSE](LICENSE)). This file lists the third-party packages that ship or run with it,
with their licenses and the copyright notices those licenses ask to keep. Tools that only build or test Bogen
(TypeScript, Vite, Vitest, tsx and the like) are not part of what ships, and are not listed.

Generated by `scripts/gen-third-party-notices.mjs` from `package-lock.json` and the license files in
`node_modules`. Do not edit by hand. After a change to the dependencies, run:

```sh
node scripts/gen-third-party-notices.mjs           # rewrites this file
node scripts/gen-third-party-notices.mjs --check   # exits 1 when it is out of date
```

## Where the packages go

| Where | What it is | Packages |
| --- | --- | --- |
| CLI | `packages/server/dist/cli.js`, one bundle made by esbuild from the server, `@bogen/core` and their dependencies. Counted from the declared dependencies, so a few the bundler leaves out as unused may be listed. | 123 |
| Shader runtime | `packages/server/dist/shader-runtime.js`, the page script that draws shader layers in renders. | 5 |
| Editor | The built editor in `apps/editor/dist`, copied to `packages/server/dist/editor`. Fonts included. | 16 |
| npm install | Not bundled: the published package `bogen-design` depends on `puppeteer-core`, `esbuild` and `tailwindcss`, and npm installs them with what they need. | 52 |

The bundles are minified and keep no license comments, so this file is where those notices live. It is included
in the npm package.

    (google/material-design-icons). The package ships no NOTICE file.
- **Component kits.** `packages/server/src/kits/` draws kits after public design systems, from their public docs and
  how they behave, with no source code copied, and with token values read from their published packages. It hands
  code off to their libraries, which are not bundled: shadcn/ui (MIT, shadcn), Radix Themes and Radix Colors (MIT,

  Design 3 (Apache-2.0, Google) with MUI (MIT) and Roboto (Apache-2.0), Ionic (MIT, Drifty Co.), Mantine (MIT,

  company, and the USWDS kit has no government banner, flag or seal. Bogen is not affiliated with any of them, and
  none of them endorses it. What may ship of each, and why, is in docs/guide/licences.md.
- **Vectorize.** Tracing an image into SVG uses `imagetracerjs` (Unlicense, public domain), listed below.
- **Colour palettes.** `packages/core/src/palette.ts` ships no third-party colour data. Its subject palettes are
  Bogen's own, its harmonies are computed in OKLCH with `culori` (MIT), listed below, and its contrast is the WCAG 2
  ratio. Two historical sets were
  considered and left out because the licence of their digitised values is unclear: Sanzo Wada's *A Dictionary of
  Color Combinations* (1933; the open datasets take CMYK values from a modern reprint and state no licence for the
  data, and the book's copyright status differs by country), and Werner's *Nomenclature of Colours* (1814, public
  domain as a book; the digitised hex values come from a sampled online edition whose terms are not stated, and the
  CC0 and CC BY 4.0 packages built on it cannot license values they did not make).
- **Font building.** Fonts drawn in a file are written as OpenType with `opentype.js` (MIT) and compressed to WOFF2
  with `woff2-encoder` (MIT), which is Google's woff2 and Brotli (both MIT) compiled to WebAssembly; both listed
  below, neither builds anything native. `packages/server/src/ofl.ts` holds the SIL Open Font License 1.1 verbatim,
  as the licence allows, so that a font derived from an OFL font carries it.
- **Accessibility engine.** `compliance_check` runs `axe-core` (MPL-2.0, Deque Systems) in the headless renderer,
  bundled into the CLI. MPL-2.0 section 3.3 allows a Larger Work that contains it to be distributed under the GNU GPL
  as a Secondary License, because axe-core is not marked "Incompatible With Secondary Licenses". Its files stay under
  MPL-2.0; their source form is the npm package `axe-core` 4.14.0 and <https://github.com/dequelabs/axe-core>, and
  the notices of what axe-core itself includes are in its `LICENSE-3RD-PARTY.txt`.
- **Fonts.** The editor's interface font is Source Sans 3 and the brand font is Archivo, both from Fontsource
  packages under the SIL Open Font License 1.1, listed below. Fonts a design uses from Google Fonts are loaded from
  Google at run time and are not part of Bogen.
